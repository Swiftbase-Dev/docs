This guide walks through setting up your first project in Swiftbase, provisioning a database table, and querying it with the Client SDK.

## 1. Create an Account and Project

1. Navigate to the [Swiftbase Console](https://app.swiftbase.io).
2. Register an account with your email, GitHub, Google, or Passkey.
3. On the dashboard, click **Create Project**.
4. Enter a project name (e.g., `acme-web`) and select your deployment region.
5. Click **Create**. Swiftbase initializes your isolated tenant, provisioning database instances, identity realms, and default storage buckets.

## 2. Define a Database Table

1. In your project sidebar, click **Databases**.
2. Select your default database (`main`) and click **New Table**.
3. Set the table name to `posts`.
4. Add the following columns:
   - `id`: Type `UUID` (Primary Key, default generated)
   - `title`: Type `VARCHAR(255)`
   - `content`: Type `TEXT`
   - `published`: Type `BOOLEAN` (Default `false`)
   - `created_at`: Type `TIMESTAMP` (Default `now()`)
5. Click **Save Table**. Your table is immediately ready and automatically provisioned with REST endpoints.

## 3. Install the Client SDK

Install the Swiftbase client library in your frontend application:

```bash
npm install swiftbase-sdk
```

## 4. Initialize and Query

Create a file named `db.ts` to initialize the client and fetch published posts:

```typescript
import { initializeSdk, db } from "swiftbase-sdk";

// Initialize with your project ID and options
initializeSdk("proj_01HZX87K9Z1X2Y3W4V5U6T7S8R", {
  baseUrl: "https://api.swiftbase.io",
});

async function loadPublishedPosts() {
  const result = await db("main")("posts")
    .select("id", "title", "content", "created_at")
    .where("published", true)
    .orderBy("created_at", "desc")
    .limit(10)
    .execute();

  console.log("Published posts:", result.data);
}

loadPublishedPosts();
```

## 5. Insert Records via the Web Console

1. In the console, open your `posts` table and click **Records**.
2. Click **Add Record**.
3. Enter a sample title and content, and toggle `published` to `true`.
4. Click **Insert**.
5. Rerun your code above. The record will be returned immediately.
