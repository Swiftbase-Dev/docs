## Config Endpoints

### List Configs
`GET /api/configs?projectId=:projectId`

### Get Config by ID
`GET /api/configs/:id`

### Create Config
`POST /api/configs`

**Request Body:**
```json
{
  "projectId": "proj_01HZX87K9Z",
  "name": "Feature Flags",
  "description": "Dynamic feature gates and limits",
  "tags": ["production", "client"],
  "config": "{\"betaSearch\":true,\"maxUploadSizeMb\":50}"
}
```

### Update Config Metadata
`PUT /api/configs/:id`

**Request Body:**
```json
{
  "name": "Updated Feature Flags",
  "description": "Updated description",
  "tags": ["production"]
}
```

### Update Config Data
`PUT /api/configs/:id/data`

**Request Body:**
```json
{
  "config": "{\"betaSearch\":false,\"maxUploadSizeMb\":100}"
}
```

### Publish Config Version
`POST /api/configs/:id/publish`

**Request Body:**
```json
{
  "message": "Promote v2 limits to production",
  "restartContainers": true
}
```

Creates an immutable snapshot version and optionally restarts connected containers to reload environment variables.

### Version History
`GET /api/configs/:id/history`

Returns previous published versions, timestamps, and commit messages.

### Delete Config
`DELETE /api/configs/:id`
