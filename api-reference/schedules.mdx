## Schedule Operations

### List Schedules
`GET /api/scheduler/schedules?projectId=:projectId`

### Get Schedule by ID
`GET /api/scheduler/schedules/:id`

### Create Schedule
`POST /api/scheduler/schedules`

**Request Body:**
```json
{
  "projectId": "proj_01HZX87K9Z",
  "name": "daily-summary-report",
  "description": "Trigger daily summary generation",
  "cron": "0 8 * * *",
  "timezone": "UTC",
  "containerId": "01HZX87K9Z1X2Y3W4V5U6T7S8R",
  "method": "POST",
  "path": "/jobs/daily-summary",
  "headers": [{ "key": "Authorization", "value": "Bearer secret_token" }],
  "body": "{\"scope\":\"all\"}",
  "active": true
}
```

### Update Schedule
`PUT /api/scheduler/schedules/:id`

Updates schedule details, cron timing, HTTP parameters, or container targets.

### Delete Schedule
`DELETE /api/scheduler/schedules/:id`

Removes the recurring schedule.
