## Schema & Tables

### List Tables
`GET /api/databases/tables?databaseId=:databaseId`

### Create Table
`POST /api/databases/tables`

**Request Body:**
```json
{
  "databaseId": "db_main",
  "name": "customers",
  "engine": "oltp",
  "columns": [
    { "name": "id", "type": "UUID", "primaryKey": true },
    { "name": "email", "type": "VARCHAR", "unique": true, "nullable": false },
    { "name": "created_at", "type": "TIMESTAMP", "defaultValue": "now()" }
  ]
}
```

## Records REST API

### Query Records
`GET /api/databases/tables/:tableId/records`

**Query Parameters:**
- `page` (number, default: 1)
- `limit` (number, default: 25)
- `filter[column]` (string): Value match filter
- `sort` (string): Column to sort by (prefix with `-` for descending)

### Insert Record
`POST /api/databases/tables/:tableId/records`

**Request Body:**
```json
{
  "email": "customer@example.com"
}
```

### Update Record
`PUT /api/databases/tables/:tableId/records/:id`

### Delete Record
`DELETE /api/databases/tables/:tableId/records/:id`

## Direct SQL & Query Execution

### Execute SQL Query or Batch
`POST /api/sql`

Executes raw SQL statements or an atomic batch of queries against the database instance.

**Request Body (Single Query):**
```json
{
  "database": "main",
  "sql": "SELECT id, email, created_at FROM customers WHERE email LIKE '%@enterprise.com' LIMIT 10"
}
```

**Request Body (Batch Queries):**
```json
{
  "database": "main",
  "batch": [
    "INSERT INTO customers (id, email) VALUES ('c10', 'test@acme.com')",
    "SELECT COUNT(*) as total FROM customers"
  ]
}
```

**Response (Single Query, 200 OK):**
```json
{
  "data": [
    { "id": "c1", "email": "alice@enterprise.com", "created_at": "2026-11-01T10:00:00Z" }
  ],
  "columns": ["id", "email", "created_at"],
  "count": 1
}
```

### Fluent Query Builder Endpoint
`POST /api/db/query`

Executes structured JSON query payloads generated by the client SDK QueryBuilder with rule enforcement and automatic field sanitization.
