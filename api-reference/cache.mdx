## Cache Operations

### List Keys & Stats
`GET /api/cache?projectId=:projectId`

Returns the list of keys matching the project along with memory and connection stats.

### Set Key
`POST /api/cache`

**Request Body:**
```json
{
  "projectId": "proj_01HZX87K9Z",
  "key": "session:usr_1049",
  "value": "{\"role\":\"admin\",\"ip\":\"192.168.1.1\"}",
  "ttl": 3600
}
```

### Delete Key
`DELETE /api/cache?projectId=:projectId&key=:key`

Deletes a single key by query parameters.

### Bulk Delete Keys
`POST /api/cache/bulk-delete`

**Request Body:**
```json
{
  "projectId": "proj_01HZX87K9Z",
  "keys": ["session:usr_1049", "temp:data"]
}
```
