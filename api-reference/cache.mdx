---
title: "Cache Endpoints"
description: "Setting, getting, and evicting in-memory key-value data via REST."
---

## Cache Operations

### Get Key
`GET /api/cache/:key?projectId=:projectId`

### Set Key
`POST /api/cache`

**Request Body:**
```json
{
  "projectId": "proj_01HZX87K9Z",
  "key": "session:usr_1049",
  "value": { "role": "admin", "ip": "192.168.1.1" },
  "ttlSeconds": 3600
}
```

### Delete Key
`DELETE /api/cache/:key?projectId=:projectId`

### Flush Prefix or Entire Cache
`POST /api/cache/flush`

**Request Body:**
```json
{
  "projectId": "proj_01HZX87K9Z",
  "prefix": "session:*"
}
```
