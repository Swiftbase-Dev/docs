---
title: "Object Storage"
description: "Uploading, downloading, and listing objects with the S3-compatible client SDK."
---

The `Storage` class in `@swiftbaseio/sdk` provides an S3-compatible interface for uploading, downloading, listing, and deleting objects within your project buckets.

## Initializing Storage

Instantiate `Storage` with target bucket settings:

```typescript
import { Storage } from "@swiftbaseio/sdk";

const avatars = new Storage({
  bucket: "avatars",
});
```

### Options

| Parameter | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `bucket` | `string` | Yes | Target storage bucket name. |
| `endpoint` | `string` | No | Custom S3 endpoint (defaults to `<baseUrl>/storage`). |
| `region` | `string` | No | S3 region (defaults to `us-east-1`). |
| `accessKeyId` | `string` | No | S3 access key ID (if using AWS SigV4 instead of Bearer token). |
| `secretAccessKey` | `string` | No | S3 secret access key. |

## Uploading Objects

Upload strings, Blobs, ArrayBuffers, or Uint8Arrays using `putObject`:

```typescript
// In a browser environment with an HTML File or Blob
async function handleFileUpload(file: File) {
  await avatars.putObject(`users/104/${file.name}`, file, {
    contentType: file.type,
  });

  console.log("Uploaded successfully!");
}

// Uploading raw text or JSON
await avatars.putObject("logs/app.log", "Log entry: Application initialized", {
  contentType: "text/plain",
});
```

## Downloading Objects

Retrieve objects as raw responses, text, JSON, or ArrayBuffers:

```typescript
// Download as parsed JSON
const config = await avatars.getObjectAsJson<{ theme: string }>("settings/theme.json");

// Download as text string
const logContent = await avatars.getObjectAsText("logs/app.log");

// Download as raw Response stream
const response = await avatars.getObject("users/104/photo.jpg");
const blob = await response.blob();
```

## Listing and Deleting Objects

```typescript
// List files in a bucket prefix
const { contents, isTruncated } = await avatars.listObjects({
  prefix: "uploads/2026/",
  maxKeys: 50,
});

for (const obj of contents) {
  console.log(obj.key, obj.size, obj.lastModified);
}

// Delete an object
await avatars.deleteObject("uploads/2026/old-temp-image.png");
```

## Presigned URLs via REST API

To generate presigned download or upload URLs for browser direct-upload, call the Swiftbase REST endpoints:

- `POST /api/buckets/urls/download`: `{ bucket: string, key: string, expiresIn?: number }`
- `POST /api/buckets/urls/upload`: `{ bucket: string, key: string, contentType?: string, expiresIn?: number }`
