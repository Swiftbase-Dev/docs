Time-Based One-Time Password (TOTP) adds an extra layer of protection to user accounts in Swiftbase.

## Enforcement Architecture

In Swiftbase, Multi-Factor Authentication is enforced at the project identity layer and handled automatically by the hosted **Universal Login** service:

1. **Project Policy Configuration**:
   - In the Swiftbase Console under **Identity > Settings**, administrators can enable `totp_enabled` and optionally toggle `totp_required`.
   - When `totp_required` is enabled, users must register an authenticator app (Google Authenticator, 1Password, Authy) upon first sign-in.

2. **Universal Login Challenge Flow**:
   - Client applications initiate the standard OAuth 2.0 PKCE flow with `loginWithRedirect()`.
   - The user enters their email and password on the Universal Login interface.
   - If the project requires TOTP and the user has not configured it, the interface presents an enrollment QR code and requires a 6-digit verification code.
   - For users with TOTP already enrolled, Universal Login prompts for the current 6-digit code before issuing the authorization code back to the client application's `redirectUri`.

## Application Integration

Because MFA is handled securely on the hosted Universal Login page, client applications do not need to implement custom TOTP challenge dialogs or manage cryptographic secrets in frontend code.

Simply initialize the SDK and invoke `loginWithRedirect`:

```typescript
import { initializeSdk, loginWithRedirect, handleRedirectCallback } from "swiftbase-sdk";

// Initialize with project configuration
initializeSdk("proj_01HZX87K9Z1X2Y3W4V5U6T7S8R", {
  baseUrl: "https://api.swiftbase.io",
  authWebUrl: "https://identity.swiftbase.io",
});

// Trigger login with MFA challenge handled seamlessly
loginWithRedirect({
  redirectUri: window.location.origin + "/callback",
});
```

When the user completes their password and TOTP challenge, they are redirected back to your application where `handleRedirectCallback()` exchanges the authorization code for an authenticated session.
