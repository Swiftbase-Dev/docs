---

The `swiftbase-admin-sdk` provides elevated, server-side access to Swiftbase infrastructure. Use it in backend APIs, worker services, scheduled daemons, and CI/CD pipelines.

## Installation

```bash
npm install swiftbase-admin-sdk
```

## Initialization

Initialize the Admin SDK using service account credentials generated in **Identity** > **Services**:

```typescript
import { initializeSdk, login } from "swiftbase-admin-sdk";

// Initialize with project ID and service credentials
initializeSdk(process.env.SWIFTBASE_PROJECT_ID!, {
  serviceId: process.env.SWIFTBASE_SERVICE_ID!,
  serviceKey: process.env.SWIFTBASE_SERVICE_KEY!,
  baseUrl: process.env.SWIFTBASE_API_URL || "https://api.swiftbase.io",
});

// Authenticate the service
await login();
```

## Key Capabilities

- **Service Authentication**: Automatically executes the OAuth 2.0 Client Credentials flow and rotates service tokens.
- **Identity Automation**: Programmatically create, update, delete, or inspect customer users, roles, and permissions.
- **Automated Migrations**: Run declarative database schema migrations in deployment pipelines before launching new container versions.
- **Direct Vault Access**: Safely read and update project secrets.
